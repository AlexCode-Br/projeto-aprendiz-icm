# Releases

O [histórico até 30/09/2026](HISTORY_THROUGH_2026-09-30.md) preserva os registros anteriores à reorganização. A última versão de produção conhecida fica em [PROJECT_STATUS.md](../../PROJECT_STATUS.md).

Cada nova publicação deve registrar em um documento datado: commit, versão Cloudflare, migrations aplicadas, resultado das verificações e pendências. Tags `vX.Y.Z` identificam releases aprovadas; atualizar a versão do pacote, por si só, não publica uma release.
